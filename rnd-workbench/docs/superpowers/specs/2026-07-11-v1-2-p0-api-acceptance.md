# 研发工作台 V1.2 P0 接口与验收基线

## 归档项目写入规则

项目成员仍可读取归档项目的工作项、活动、评论、附件和导出；任何写请求统一返回 `1005`，提示“项目已归档，仅可查看和导出”。

覆盖范围：工作项创建、编辑、状态变更、分配给我、批量更新、批量删除、评论、附件上传/删除、成员调整、模块和迭代调整、项目基本信息编辑。

## 项目管理权限

| 接口 | 系统管理员 | 项目管理员 | 成员/访客 |
|---|---|---|---|
| `GET /projects` | 本人加入且未归档项目 | 本人项目 | 本人项目 |
| `GET /projects/manage` | 全部项目（含归档） | 不允许 | 不允许 |
| `PUT /projects/{id}` | 允许 | 本人担任管理员的项目 | 不允许 |
| `POST/PUT/DELETE /projects/{id}/members` | 允许 | 本人担任管理员的项目 | 不允许 |
| `PUT /projects/{id}/archive` | 允许 | 不允许 | 不允许 |

`GET /projects` 每个项目增加 `currentUserProjectRole` 字段，值为 `PROJECT_ADMIN`、`MEMBER`、`GUEST` 或 `null`。

## 验收用例

1. 系统管理员新建项目后自动成为该项目管理员，工作项空列表返回成功。
2. 系统管理员可在未加入某项目时设置该项目团队；项目内容读写仍需先加入该项目。
3. 归档项目的成员尝试创建工作项，接口返回 `1005`；读取、下载和导出仍正常。
4. 项目管理页默认只显示进行中项目，支持名称/简称、状态及“我负责”筛选。
5. 项目管理员可看到“编辑、设置团队”；成员和访客仅看到“进入项目”。
6. 项目管理页显示项目名称、状态、项目管理员、成员数、最近更新时间和操作，侧栏不显示项目快捷列表。
7. 首页的今日到期和 P0 数字来自真实工作项查询；空项目返回 0。
