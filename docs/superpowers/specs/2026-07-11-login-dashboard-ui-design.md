# 登录页与工作台 UI 升级设计

日期：2026-07-11  
状态：已确认，待实施

## 1. 目标与范围

将现有研发工作台升级为“明亮协作空间”视觉风格。设计参考以大留白、低对比边框、柔和状态色和清晰信息层级为主，不复制参考图的页面内容或配色。

本次仅调整以下静态前端资源：

- `rnd-workbench/src/main/resources/static/index.html`
- `rnd-workbench/src/main/resources/static/styles.css`

不修改后端接口、数据结构、页面路由、元素 ID 或既有交互语义。现有桌面端最小宽度策略保持不变，不新增移动端适配。

## 2. 视觉基础

- 背景：暖白与极浅灰蓝，降低页面大面积纯白造成的割裂感。
- 品牌主色：协作绿，用于主按钮、激活导航和高优先级操作。
- 辅助色：浅蓝用于信息与协作、暖黄用于临近到期或需关注状态、红色仅保留给风险与错误。
- 表面：卡片使用细边框、12–16px 圆角和轻柔阴影；普通内容不重复堆叠重阴影。
- 字体与间距：沿用系统字体栈，扩大主区块留白，压低非核心文案的对比度。

## 3. 登录页

登录页从单一居中卡片改为桌面双栏布局：

- 左栏为品牌叙事区，展示“协作更顺畅，交付更有把握”及简短说明，使用薄荷绿、浅蓝与暖黄的抽象几何背景。
- 右栏为登录表单，保留现有账号、密码、错误提示与提交行为；通过清晰标题、标签、输入焦点和主按钮建立阅读顺序。
- 窄屏时双栏按现有可用宽度降级为单栏，隐藏左栏装饰而不隐藏登录功能。

## 4. 工作台

### 4.1 全局框架

- 左侧导航保留项目切换、主导航、项目列表、收藏、已保存筛选和用户信息；激活项使用浅绿底与深绿文字，品牌标识改为协作绿渐变。
- 顶栏保留搜索、快速创建、通知和退出；搜索框使用柔和填充，快速创建作为唯一高强调按钮。
- 页面标题区保留当前项目与 Sprint 上下文，并以更舒展的间距分隔标题、操作和正文。

### 4.2 工作台首屏

- 在统计卡前增加欢迎与协作焦点区：左侧显示当前用户、今日工作提示和团队推进状态；右侧展示一个可复用的“协作动态”摘要。仅复用已有数据和页面文字，不新增接口请求。
- “我的待办、待接收、处理中、待验收”四个既有统计卡保留原 ID 和数据绑定，改为轻量卡片；通过小型状态色标和重点数字突出优先级。
- “我的待办、项目动态、逾期/即将到期”等现有面板保持内容顺序和按钮行为，使用一致的面板标题、列表行悬停和状态标签。

## 5. 实施约束

- JavaScript 选择器和动态渲染依赖的 DOM ID、class 与数据属性不得被删除或改名；如新增包装元素，不改变既有事件委托路径。
- 颜色仅承担状态和操作层级，不以颜色作为唯一信息载体。
- 登录错误、禁用、悬停和键盘焦点均保留明确可见的状态。

## 6. 验证标准

1. 登录页在默认桌面宽度和窄屏宽度下均完整可见，登录、错误提示与提交逻辑不变。
2. 工作台能正常渲染统计卡、待办、项目动态和到期列表，项目切换、搜索、快速创建、通知、退出及侧栏收起仍可用。
3. 前端 JavaScript 语法检查通过，Maven 测试与打包通过。
