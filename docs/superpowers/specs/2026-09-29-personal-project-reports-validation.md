# 我的任务、项目看板与项目报表：验收记录

日期：2026-09-29。方案 A，本地开发与验证完成，未部署或重启原有服务。

## 已实现

- 我的任务作为登录默认页面，默认跨全部可访问项目统计自己的任务；个人概况、流程待处理、我的项目、已提交及已验收分别展示。
- 项目看板展示项目档案、任务/工时指标、状态与类型分布、人员工时对比、近六个月趋势、人员明细、里程碑、风险与动态；数字和图表可下钻任务。
- 项目报表支持项目、当前负责人、日期范围、任务类型、状态筛选，以及项目/人员/时间/类型四种汇总，周/月分组，汇总与明细 CSV 导出。
- 分区菜单及专用导航调用已注释；项目档案分区字段隐藏，保存不会覆盖原值；后台字段、历史数据及分区实现保留。
- 修复跨项目任务列表每项目仅加载前 200 条的问题；修复跨账号切换时旧任务数据和菜单计数残留；详情操作入口按已有权限显示。
- 新页面沿用现有主题；390px 窄屏使用可展开侧栏，图表自适应，表格在自身容器横向滚动。

## 数据口径

- 已完成在新页面显示为待验收；未完成为新建、进行中、延期处理、验收不通过；已验收、已拒绝分别统计。原任务管理中的未完成任务入口仍采用原有未关闭口径（包含待验收）。
- 预计与实际工时为任务累计登记值，空值不视为零，明确显示未登记任务数。
- 报表默认按任务完成日期筛选，只包含当前待验收/已验收且有完成日期的任务。可切换创建日期，所有列统计同一批筛选后任务。
- 人员归属为当前负责人，不还原历史转交；完成任务工时按上海时区实际完成日期归集，不代表每天实际投入。
- 任务验收率为已验收/(任务总数-已拒绝)，不是项目进度。
- 权限沿用项目成员范围（不包含已归档项目），访客只读；后端基于完整筛选集合汇总，不依赖前端列表页。单次导出超过 10000 行明确拒绝，不截断。
