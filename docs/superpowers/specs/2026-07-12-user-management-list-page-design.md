# 用户管理列表页设计

日期：2026-07-12  
状态：已确认，待实施

## 目标

将系统管理员的“用户管理”从弹框改为与“项目管理”一致的主内容区列表页面，提升用户数量增长后的搜索、筛选和操作效率。

## 范围

- 仅系统管理员可见、可访问用户管理页面和接口。
- 保留新增用户、编辑、启用/禁用、重置密码全部既有能力。
- 新增和编辑继续复用既有用户编辑弹框，不改变现有用户接口。
- 移除用户管理列表弹框；不移除用户编辑弹框。

## 页面规则

1. 点击左侧“用户管理”后，在主内容区展示列表页面；隐藏项目工作台、工作项工具栏和看板。
2. 页面标题为“用户管理”，副标题说明“管理员可维护用户状态、组织资料和系统权限”。
3. 顶部操作区包含：姓名或邮箱关键字搜索、账号状态筛选（全部、启用、已禁用）和“+ 新增用户”。
4. 列表列固定为姓名、邮箱、部门/岗位、系统权限、状态、操作。
5. 操作列保留编辑、启用/禁用、重置密码；重置密码仍需二次确认。
6. 非管理员点击入口或直接触发用户页时，显示无权限提示，不请求用户列表。

## 验收标准

- 用户管理不再以列表弹框方式打开。
- 管理员可在列表页搜索、按状态筛选、新增、编辑、启停和重置密码。
- 普通用户看不到入口且不能加载用户管理列表。
- 从用户管理切回项目管理、工作项或看板时，主内容区恢复对应页面，不残留用户管理样式。
