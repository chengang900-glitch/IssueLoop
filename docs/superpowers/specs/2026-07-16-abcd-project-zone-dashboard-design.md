# ABCD 项目分区看板设计说明

## 1. 目标

在现有项目任务管理系统中增加 ABCD 工作分区能力，让项目按“硬仗清单、调优策略、部门级重点工作、日常周期性工作”四类集中展示。项目档案负责维护分区属性，分区看板负责跨项目查看、筛选及切换展示方式。

## 2. 工作分区字段

项目档案新增“工作分区”字段，选项固定为：

- A：硬仗清单
- B：调优策略
- C：部门级重点工作
- D：日常周期性工作
- 未分区

默认值为“未分区”。历史项目在数据库升级时统一补为“未分区”。

该字段放在项目档案“基础身份”区域。系统管理员或该项目的项目管理员可以修改，其他成员只读。后端必须校验字段值，拒绝固定选项以外的数据。

## 3. 导航与权限

左侧主导航在“任务看板”之前增加“分区看板”。

- 普通用户：只展示自己参与且未归档的项目。
- 系统管理员：展示全部未归档项目。
- 未分区项目：不出现在分区看板。
- 已归档项目：不出现在分区看板。

点击任何项目进入该项目的项目档案页面。

## 4. 页面结构

页面标题为“ABCD 分区看板”。主体按 2×2 四象限布局：

- 左上 A区：硬仗清单，红色主题。
- 右上 B区：调优策略，蓝色主题。
- 左下 C区：部门级重点工作，绿色主题。
- 右下 D区：日常周期性工作，琥珀色主题。

每个分区包含醒目的分区字母、分区名称、当前筛选结果数量和项目集合。颜色用于分区识别，正文和状态仍沿用系统现有设计语言，避免装饰过重。

桌面端保持四区同时可见；窄屏端改为单列依次展示 A、B、C、D，避免卡片或字段被压缩。

## 5. 过滤栏

四分区上方增加统一过滤栏，包含：

- 关键词：按项目名称模糊搜索。
- 项目经理。
- 当前阶段。
- 项目状态。
- 健康状态。
- 计划结束日期起止范围。
- 重置筛选。

筛选在浏览器端实时执行，同时作用于 A/B/C/D 四区，并实时更新各区项目数量。项目经理选项从当前可见项目涉及的项目经理中去重生成。空条件表示不限。

## 6. 列表视图

默认采用列表视图。每个分区中的项目以紧凑课表行显示：

- 项目名称
- 项目经理
- 当前阶段
- 项目状态
- 健康状态
- 计划结束日期

分区内按计划结束日期升序排列；未填写计划结束日期的项目排在最后。日期相同时按项目名称排序。

## 7. 卡片视图

过滤栏右侧提供“列表视图 / 卡片视图”切换按钮。

切换为卡片视图后，四区结构保持不变，区内项目改为矩形圆角卡片。卡片仍只展示已确认的六项信息，不增加客户、编号或其他字段。卡片使用分区主题色作为顶部强调线或侧边强调线，不使用大面积高饱和背景。

视图偏好保存到当前浏览器，下次进入分区看板时恢复上次选择。筛选条件不做长期保存，刷新页面后恢复默认。

## 8. 空状态与异常处理

- 某分区没有项目时显示“当前没有项目”。
- 某分区因筛选无结果时显示“没有符合条件的项目”。
- 项目经理不存在或未配置时显示“未设置”。
- 计划结束日期未配置时显示“未设置”。
- 数据加载失败时显示错误提示和“重新加载”按钮，不影响其他菜单使用。

## 9. 数据与接口改动

数据库为 `projects` 表新增 `work_zone` 字段，默认值为“未分区”，并建立适合分区查询的普通索引。

项目实体、创建/更新请求和项目 DTO 增加 `workZone`。项目创建默认“未分区”；项目更新沿用现有项目管理权限。分区看板复用现有项目列表和项目成员接口，不新增独立统计表或冗余数据。

## 10. 验证标准

- 新建和历史项目默认显示“未分区”。
- 只有系统管理员或项目管理员可以修改工作分区。
- 分区看板位于任务看板之前，并按权限展示项目。
- 未分区及已归档项目不出现在四区。
- A/B/C/D 四区名称、颜色和项目数量正确。
- 六个筛选条件同时作用于四区，重置后恢复全部结果。
- 列表和卡片视图可切换，刷新后保留视图偏好。
- 项目排序、空状态及点击进入项目档案正确。
- 桌面 2×2 和移动端单列布局无重叠、裁切或横向滚动。
- 后端测试、数据库迁移测试、前端语法检查和实际浏览器交互验证全部通过。

## 11. 非本次范围

- 不提供拖拽项目跨分区。
- 不在分区看板直接修改项目分区。
- 不展示“未分区”项目区域。
- 不新增分区统计图表、导出或批量分区功能。
