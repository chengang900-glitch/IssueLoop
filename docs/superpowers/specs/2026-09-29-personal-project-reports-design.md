# 我的任务、项目看板与项目报表

用户已批准方案 A 并授权实施。不增加工时填报、不修改既有任务流转权限、不迁移或删除历史分区数据。

- 我的任务为登录首页，默认所有可访问、未归档项目；负责人维度的个人概况与有权处理的验收/延期事项分开统计。进行中、逾期、未来七天到期卡片可重叠。我的项目显示个人任务分布。
- 项目看板必须选择单项目，包含档案、累计任务与工时、状态、类型、人员对比、最近六个月新增/完成趋势、里程碑、风险、近期动态及可下钻明细。
- 项目报表支持项目、人员、类型、状态、日期口径及日期范围筛选，项目/人员/类型/时间汇总，周/月分组，汇总和明细 CSV 导出。
- 已完成在分析页面显示为待验收，已验收单独展示。未完成包含新建、进行中、延期处理、验收不通过；待验收单列。逾期仅指未完成且截止时间早于当前时间。
- 预计工时与已登记实际工时分别汇总；缺失不视为零，并显示未登记数。实际工时不代表工时日志。完成任务工时仅包含当前已完成/已验收、具有实际完成时间的任务，按上海时区完成日期归集；人员归属为当前负责人。
- 报表日期口径默认完成日期，可切换创建日期；全部列均描述所选日期口径的任务集合。时间组遵循所选日期口径，图表新增/完成趋势分别用创建/完成日期。
- 任务验收率为已验收/(总数-已拒绝)，不代表项目进度。零分母显示无有效任务。
- 所有统计先在后端按项目成员权限限定完整集合，再做汇总与明细分页。导出重用相同筛选，上限 10000 行，超过明确拒绝，禁止截断。
- 分区菜单和专用调用注释停用，分区代码及字段保留；项目档案隐藏分区字段且保存不覆盖旧值；项目简报入口改为项目看板。

验收：个人与项目数字不混淆；超过 200 条任务统计完整；访客不可操作任务，非成员不可读取统计/导出；空值、跨月/上海日期边界正确；筛选、下钻、导出一致；原任务创建、查看、流转仍可使用。
