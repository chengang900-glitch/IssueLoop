# 研发工作台第一阶段实施计划

1. 新增全局工作项计数表与原子编号生成器；验证连续和并发调用不重复。
2. 集中补充项目写权限校验；覆盖工作项、评论、附件、模块和 Sprint 写接口。
3. 修复通过资源 ID 访问时的项目归属校验，并统一附件目录、大小及 MIME 校验。
4. 为状态机、“分配给我”、权限和附件规则补充单元测试。
5. 保留现有 HTML/CSS，增加登录层并将原型脚本替换为真实 API 数据流。
6. 同步根目录原型与 Spring Boot 静态资源，执行 JavaScript 语法检查。
7. 执行 Maven 测试和打包；若环境缺少 PostgreSQL，仅把真实数据库启动验收列为待执行项。
